Apache DataFusion
What is DataFusion

A query engine you embed, then extend

01SQL parsersqlparser-rs → ASTstock
02Logical plannerAST → LogicalPlanstock
03Physical planner+ our ExtensionPlannerextended
04Optimizer rules+ our 3 streaming rulesextended
05Vectorized executorPulls Arrow RecordBatchesstock

Apache DataFusion is an extensible SQL query engine in Rust. It uses Apache Arrow as its in-memory format. Streamling runs on DataFusion 54.

01
Full SQL without writing an engine

Parser, planner, optimizer, UDFs and a vectorized executor are ready to use.

02
Four extension points, no fork
TableProviderSources and sinks become tables
ExecutionPlanCustom physical operators
ExtensionPlannerLowers our custom nodes
PhysicalOptimizerRuleRewrites the plan (we have 3)
03
Lighter than Flink for our workloads

CDC fan-out, enrichment, dedup: no distributed shuffle needed. Pipelines go from paused to running in about 5s.

We extend its extension points. We do not fight it.06 / 11

A streaming source is a TableProvider that never ends

Same plan, same SQL, same executor

Only the bottom node differs. Filter, Projection and UDFs above the scan are stock DataFusion.

Quick start
Try it yourself

Build from source and run your own pipeline

1
Clone the repo

Needs Rust via rustup. The repo pins its toolchain.

2
Build with Cargo

One release binary: target/release/streamling.

3
Create some data

A CSV in ./data/ acts as a bounded source.

4
Write pipeline.yaml

Source → SQL filter → print sink.

5
Run it

Rows 2 and 3 print, then the job ends. Set type: continuous to keep polling.

~/streamling — zsh
# 1. clone
git clone https://github.com/goldsky-io/streamling && cd streamling
# 2. build
cargo build --release --bin streamling
# 3. data
mkdir -p data && printf 'id,amount\n1,500\n2,1500\n3,2500\n4,750\n' > data/tx.csv
# 4. pipeline.yaml
sources:
  raw_transactions:
    type: file
    path: ./data/
    format: csv
    primary_key: id
    mode: { type: bounded }
transforms:
  large_transactions:
    type: sql
    primary_key: id
    sql: SELECT * FROM raw_transactions WHERE amount > 1000
sinks:
  print_large: { type: print, from: large_transactions }
# 5. run
./target/release/streamling pipeline.yaml
